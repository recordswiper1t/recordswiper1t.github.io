V3 changes

  • iPhone taps: updated Ruffle web runtime and disabled Safari pan/zoom/callout handling over the game surface so taps stay with the Flash player and map consistently.
  • Pause/settings tools: 1×/3× and +100 coins are inside the in-level paused tools instead of floating over the battlefield.
  • Heroes: choose 0 through 7 heroes in a level. Hero skill-point balances are recalculated to exactly the points still needed to max each hero.
  • Stars: the game now grants only the stars still needed to finish the normal 65-star upgrade tree, rather than 999,999.
  • Enemy tools: the second settings page lets you select an enemy, count and path, then send a custom round.
  • Waves: a button sends every remaining normal wave at once.
  • Special towers: normal build spots get a second radial page for the non-standard Dwarf Riflemen and Pirate Barracks towers.
  • Previous mods retained: all tower/hero access unlocks, fast boot, and Heroic/Iron availability remain included.

Using V3

Inside a level, open the game's pause/settings screen to see the V3 controls. The enemy-round page is reached from there. On an empty build spot, use More… to reach the special-tower page.

Your campaign save and stored SWF remain separate. Switching among V3, v2, v1 and clean builds uses the same Ruffle site storage.

Use ⋯ → Saves / backup occasionally. Clearing Safari website data can remove local progress.
