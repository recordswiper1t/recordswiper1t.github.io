Progress + mods

The game file and progress are separate. The SWF lives in IndexedDB; Ruffle keeps Flash SharedObject saves in site storage. Replacing the SWF with a compatible modified build does not intentionally delete those saves.

For tower-stat work, we will patch a copy of this exact Archive.org build, then load the modified copy with Use a modified SWF instead. The player keeps the canonical movie name kingdom-rush-frontiers.swf so compatible builds use the same save identity.

Use ⋯ → Saves / backup while playing and export a Ruffle save occasionally. Clearing Safari website data can erase browser storage.
