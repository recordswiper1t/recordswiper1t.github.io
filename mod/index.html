How modding works

Start with a copy of the game you are entitled to use. We can edit that exact SWF — for example tower damage, range, fire rate, upgrade costs and other constants — then you replace the stored file here with the modified SWF.

Your progress is kept separately from the SWF file. Replacing the stored build does not intentionally delete the Ruffle save data, and this player always uses the same canonical movie name so compatible builds can continue the same progress.

The SHA-256 shown above identifies your exact game build. Tower-stat patch locations are version-specific, so that hash lets us make edits safely instead of guessing offsets.

Save safety

While playing, open the ⋯ menu and choose Saves / backup. If iPhone does not open Ruffle's menu from the button, press and hold inside the game, then use Ruffle's Save Manager to export a backup.

Important: Safari can remove site storage when website data is cleared. Keep occasional save exports if the progress matters.
