# Kingdom Rush Frontiers sandbox mod

The recommended laptop version is the native Ruffle build in `desktop/`.

## Play on Windows

Download this repository as a ZIP, extract it, then double-click:

`desktop\run-native.bat`

The launcher downloads Ruffle on first use and automatically selects the newest verified SWF in `assets/`.

## macOS / Linux

Run:

`sh desktop/run-native.sh`

See [`desktop/README.md`](desktop/README.md) for renderer troubleshooting, performance settings, sandbox controls, scoring and build details.

## Release verification

The current game mod is built and re-export verified with FFDec before publication. Matching `V*-SHA256SUMS.txt` and `V*-BUILD.txt` files in `assets/` document each verified release.
