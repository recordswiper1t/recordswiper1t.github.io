Kingdom Rush Frontiers

Persistent iPhone mode runs your own SWF in Ruffle on this site. The SWF stays on this device, and Flash save data stays under this GitHub Pages origin so it can be backed up and later edited.

The game file is not uploaded to GitHub or any server. Use a copy you are entitled to use. Safari site-data clearing can erase browser saves, so make periodic Ruffle save backups.

This keeps your previous embed available. Its save storage belongs to the embedded site and is separate from Persistent mode, so it is not the mode we will mod.

Saving on iPhone

  1. Play normally. Ruffle stores Flash SharedObject save data in browser storage automatically.
  2. Tap Saves to try opening the Ruffle menu. If iOS blocks the synthetic menu, press and hold inside the game area instead.
  3. Choose Open Save Manager in Ruffle to download a backup. That backup is what we can inspect and mod next.
  4. For the most app-like setup, open this page in Safari, use Share, then Add to Home Screen.

Do not clear Safari website data for this GitHub Pages site until you have exported a save backup.
